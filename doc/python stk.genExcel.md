# genExcel

生成excel模板

## 1. 使用

- 命令：`stk genExcel --mode [reg/itf/crg] xxx.xlsx`
- 输出：在当前目录下，生成命令中命名的excel文件
- 约束：该命令只能在Windows下使用，因为linux缺少excel的部分支持。

## 2. reg格式

![img](https://img2023.cnblogs.com/blog/898240/202407/898240-20240726165558473-753845052.png)

1. data_width必须为10进制数，且为8的倍数							
2. addr_width必须为10进制数							
3. base_addr必须为16进制数，以0x开头							
4. reset_value必须为16进制数，以0x开头							
5. 多bit域，域的格式为MBS:LBS，单bit域可以用MBS:LBS格式，也可以直接写bit的索引
6. 寄存器位宽可以大于data_width,rtl会拆分成多个寄存器，寄存器模型访问会访问多次						
7. offset_addr必须为16进制数，以0x开头。地址后\*N表示有N个相同的寄存器，地址分别为offset_addr+i\*(data_width/8),i从0开始			
   - \*N后rtl对应reg_name0~reg_nameN-1,bd_path只需要填到reg_name即可，寄存器模型对应reg_name[0]~reg_name[N-1]
   - \*N后，寄存器占用N\*(data_width/8)个地址


## 3. itf格式

![img](https://img2023.cnblogs.com/blog/898240/202407/898240-20240726165452080-1342937240.png)

1. "汇总"页签包含所以接口列表，点击接口链接可以跳转到相应接口页签			
2. 接口页签的第一行为接口名字，点击名字可以跳转到"汇总"页签			
3. 接口名字可以修改，减少生成agent名字的长度			
4. 接口页签包含接口信号描述和信号域描述，域描述紧随接口信号			
5. 信号描述行第1个单元格不为空，域描述行第1个单元格为空			
6. 域描述行的第1个单元格是空白，不能添任何内容，第2个单元格为域的场景名（可以为空）			
7. 域描述行的第3个单元格为域名，第4个单元格为域位宽，第5个单元格为域描述			
8. 域描述行的第3个单元格为域名，第4个单元格为域位宽，第5个单元格为域描述			
9. 域描述行的第2-5列有底色			
10. 修改规则			
   - 接口名可以随意修改			
   - 可以添加接口信号			
   - 可以为接口信号添加域			
   - 添加的信号和域用橙色底色标识			
   - 域描述行的场景名可以添加场景使用条件，比如SIGNAL xxx = 3:CYCLE 3\nscene_name
